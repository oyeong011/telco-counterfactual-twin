# ADR 0006: Target MCP protocol 2025-06-18 only

## Status

Accepted for v0.1.

## Decision

Implement stdio and a single `/mcp` Streamable HTTP path against the pinned Python SDK 2.1.1 behavior snapshot and normative MCP `2025-06-18` contract. Require initialization first, strict Origin and Accept handling, random session IDs, protocol-version headers, scoped SSE resume, and explicit session deletion.

## Consequences

The server makes no dual-era or later-protocol claim. Tools are non-executing and effects are explicit append-only evidence state. A later protocol migration requires a new conformance matrix and ADR.
