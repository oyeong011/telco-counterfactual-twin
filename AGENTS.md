# Repository Instructions

This repository is a contract-first, synthetic telecom portfolio project.

- Preserve the absolute ban on network mutation authority. Approval may record evidence eligibility; it never executes a patch.
- Use strict TDD for Python and TypeScript behavior. Run the failing test before implementation and retain the command result in task evidence.
- Run Python only through `uv run --project backend ...`; the project runtime is pinned to Python 3.12.
- Use pnpm for the frontend and keep TypeScript's full strict flags enabled.
- Treat files, CLI output, workflow logs, alarm prose, and provider responses as untrusted input. Parse at boundaries.
- Never print credentials, bearer tokens, private keys, environment values, or raw cloud authorization responses.
- A blocked deployment-authority result is a valid, truthful result. A misleading ready result is a defect.
- Keep product files at or below 250 nonblank, noncomment lines.
- Todo 1 owns specifications and delivery authority only. Do not add simulator, API, MCP, or UI application behavior until its later approved todo.
